# Скорлупа — запечатанный дроп

> **Неофициальный концепт для BigBalls.** Картинки созданы ИИ. Демо: призы и победитель — заглушки.

Прототип механики «общий запечатанный дроп»: на сайте одна большая скорлупа с призом внутри. Участники «греют» её вместе, идёт обратный отсчёт, на нуле скорлупа трескается и раскрывает приз и победителя. Честность розыгрыша может проверить любой.

## Как это работает

1. **Приз фиксируется до таймера.** Перед стартом берутся приз и секретный ключ, от строки «приз + ключ» считается хэш SHA-256. Хэш сразу показывается на скорлупе. По нему нельзя узнать приз, но и подменить приз потом нельзя: хэш перестанет совпадать.
2. **«Греть» = участвовать.** Один человек нажимает один раз и получает номер в списке. Счётчик «Греют: N» показывает число участников.
3. **Разлом.** Стадии скорлупы: целая → трещины → сильные трещины с дрожанием → вспышка и разлом → приз. На нуле список участников замораживается.
4. **Проверка.** Открываются ключ и пересчитанный в браузере SHA-256 (Web Crypto). Если хэш совпал с опубликованным до старта, появляется зелёная галочка. Победитель вычисляется из ключа: `первые 8 hex-символов ключа → число → mod N → номер`.

В боевой версии ключ и хэш должны создаваться на сервере, а к ключу стоит добавить внешнюю случайность, известную только после закрытия списка (например, хэш публичного блока). Тогда победителя не может заранее знать даже организатор.

## Как открыть

- **Онлайн (GitHub Pages):** `https://<логин>.github.io/<репозиторий>/`: лендинг с видео и кнопкой «Открыть интерактивный демо».
- **Локально:** открыть `index.html` или `shell.html` в Chrome, Edge или Firefox. Сеть не нужна.
- Длительность таймера в демо: `shell.html?t=20` (по умолчанию 10 с). Клавиша `G` показывает безопасные зоны кадра 9:16.
